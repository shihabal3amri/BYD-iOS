Add to AltStore Classic Download IPA · 339 MB

AltStore Classic must already be installed and configured. Open this page in Safari on your iPhone. This project is free; initial AltStore setup still requires a computer. The downloaded IPA must be signed by an installer.

Install or update

  1. Tap Add to AltStore Classic and confirm adding the source.
  2. Find BYD Localized in AltStore, review permissions and install with your own Apple account.
  3. Open BYD and sign in to your own BYD account. Go to Me → Settings to choose your language and bottom tabs.

Already installed? Refresh the source in AltStore, then open My Apps → BYD → Update. Look for 9.16.0 · Revision 2. Keep your existing app and use the same Apple account.

For normal AltStore Classic use, keep AltServer reachable through the same Wi-Fi network or USB. Free Apple-account signing needs refreshing within seven days. Read the installation guide.

Installing with Impactor

Download the IPA and import it into Impactor. On the package options screen, change Name from the Chinese text to BYD, then sign and install with your own Apple account.

If you see Developer API error 35 about a missing appIdName, set Name to BYD and retry with the same IPA. Keep the default identifier and app-group handling. Read the Impactor instructions.

Make it yours

  • Choose English, Arabic or Russian.

Fully close and reopen BYD after changing language. Tab visibility changes immediately.

Bluetooth badges restored

Revision 2 restores Bluetooth badges on supported dashboard controls. The fix uses BYD’s original artwork and keeps connection and control logic unchanged. AltStore installation and startup were verified with the previous release on an iPhone XS.

Some Chinese content and artwork remain. The profile page may be blank. Wakeup unlock is not included. Other iPhones and iOS versions require testing.
